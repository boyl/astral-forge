# 第一阶段：稳定加载与开发者 SDK

版本：0.1.2-dev。范围：星界战士 Steam Windows x64 2.6.4。

## 改进

1. 修复 IDXGIFactory2::CreateSwapChainForHwnd 转发中遗漏 HWND 参数的问题。保留完整虚表副本，但依据已查询接口的实际公开槽数决定哪些入口可以挂钩；不把副本容量当作接口能力。
2. 默认仅加载插件，渲染需显式开启。加载核心、纯加载入口与渲染入口分别测试，保留 BD 的 version.dll。
3. 初始化失败和异常时清理 DLL 自己注册的帧订阅与 detour；同步等待当前帧派发完成后清理模块订阅。只支持代码位于原生 DLL 中的回调与 detour。
4. 配置字符串不再共用可变 scratch；释放核心持有的插件 API 表；取消 DllMain 中的复杂清理；提供幂等显式关闭，调用者须先停止渲染与插件线程。
5. 安装器按哈希预检、备份、验证与回滚，拒绝覆盖未知入口。卸载保留插件与配置，文件漂移时在删除前拒绝整次操作。
6. 保留 ABI 1 前缀，新增能力查询、C/C++ 插件模板、独立编译和开发指南。

## 验证

- MSVC 原生构建、C 公共头编译、原 128 字节 API 前缀、代理导出一致性。
- 引擎函数定位正反例、传统交换链 Present、Factory2 HWND 交换链与 Present1、解除挂钩恢复。
- 失败和异常初始化、资源清理、重复关闭、中文 DLL entry、越界 entry 拒绝。
- 安装预览不写入、未知加载器保护、安装/升级、真实文件锁造成的部分安装和卸载失败回滚、漂移卸载拒绝、插件与配置保留。
- 实机纯加载与渲染入口启动，持续响应并确认 BD 模块同时加载；随后恢复原文件哈希。此项仅证明启动冒烟，未证明完整 BD 菜单交互、战斗、转场、长时间运行或全部显卡兼容。

## 正常流程实机验收（2026-10-03）

通过复用 BD 自动化的普通扫描码输入，在隔离存档完成主菜单选择、存档选择、进入大厅、移动及下落、索瓦菜单开局、传送进入生成场景、守卫赐福选择、进入战斗房间、敌人攻击致死、死亡结算返回大厅和再次开局。全程不写玩家坐标或血量，不调用私有开局/场景切换函数；只读观察器与截图用于核对输入效果。

公开 state_watch 记录大厅 epoch 5、开局 epoch 6、生成场景 epoch 7、战斗房间 epoch 8、死亡后大厅 epoch 9、再次开局 epoch 10。生成场景与战斗房间都使用 layout_game，说明 scene_index 不充当房间 ID；本轮同 layout 重建时 epoch 更新。血量从大厅 300/300 到新场景 450/450，再被敌人攻击逐步降至 0/420；结算期间玩家对象仍存在，返回大厅恢复 300/300。零血量不能作为通用原生死亡事件。

本轮持续响应采样 720 秒，流程完成后主动关闭隔离游戏，原定 1200 秒启动冒烟因此记录“提前退出：0”；保留该原始结果，不将其改成完整 1200 秒通过。生命周期流程有独立记录，文件回滚成功，原核心与原存档基线哈希一致。既有未知版本、旧 ABI、独立 SDK 示例、加载/渲染及安装回滚契约结合本轮正常流程，满足进入下一阶段的门禁。双人实机、所有地图及长期战斗不在本轮覆盖范围内。

## 0.1.6-dev 原生加载链路增量（2026-10-03）

修复 x64 指令解码器漏识别寄存器 push/pop（0x50..0x5f）的缺陷，覆盖无前缀、REX 和操作数宽度前缀。新增独立长度/截断检查及 48 个真实可执行序言的安装、调用、撤销和原字节恢复测试；完整构建、插件契约和安装器回滚检查通过。ABI 1 及默认能力位 743 保持不变。

隔离私有图片探针确认首次加载、缓存查询及纹理创建路径。原生格式存在压缩、裁剪和拉伸缓冲，不能按逻辑尺寸直接覆盖原缓冲。自制 RGBA8 图经原生分配及预乘处理后，图片 ID 0 从压缩格式 2 转为格式 0，原生渲染器创建 864×336 纹理；后续原生对象保留纹理且 CPU 指针清空。该记录证明上传及对象状态，不单独证明画面、方向、透明度或分配器实际释放。

直接挂钩上传包装入口因短相对跳转被拒绝；全局释放入口因相对修正超出距离被拒绝。保留保护条件，撤去不必要的全局释放挂钩，使用低层纹理入口与对象状态观察。失败插件初始化后，其已安装挂钩及图片资源按核心归属回滚。

原生替换仅为任务目录内的隔离研究探针，不进入预览包或公开 SDK，不开启原生资源能力位。仍需完成可见资源定位、画面方向/透明度、跨场景缓存、冲突与插件卸载归属后，才开放运行时接口。

本轮隔离会话持续 150 秒响应，完成文件回滚，四个原存档文件哈希一致。主菜单截图没有显示 ID 0 测试图，否定其为标题图的猜测；下一步从绘制调用的图片对象定位实际图片 ID，上传通过不作为可见替换通过。
