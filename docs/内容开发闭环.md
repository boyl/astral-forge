# 内容开发闭环（少量开发者试用）

用户已确认六项范围：光环、技能、回血与施法资源、原生玩法事件、插件自有持久数据、共享菜单。先支持已验明的 Windows x64 2.6.4 单人；向大量开发者演进，按少量开发者试用标准验收。完成标准是两个只依赖公开 SDK 的示例在隔离实机中完成构筑选配和事件响应，不以加载成功替代内容验收。

最新技能换房与独立进程续局、最终双示例同进程回归 102 及其预设重启 106 均已通过。交付覆盖以[试用验收矩阵](试用验收矩阵.md)为准。

## 边界与证据

插件 → 公开 C ABI → 核心服务 / 精确版本游戏适配器。保留 ABI 1，只在 248 字节旧前缀后追加；冻结旧二进制回归。UI 使用 MVC：菜单模型管理筛选、选择、草稿与执行结果；控制器转换键鼠动作；视图根据运行时测量绘制并命中同一矩形。插件选择玩法，框架提供操作与结果，不承载 BD 配方。

本地 BD `runtime.js` 可作为原生机制的定位证据，原项目不修改。相同 EXE 指纹下，装备字典位于 RVA `0xc0d5cb0`，光环 `P1_relic_1..5`、技能 `P1_spell_1..4`；刷新入口 `0x1450440`、符文刷新 `0x3582dc0`。BD 另有检查点快照与原版保存入口同步，不能只写装备 ID 并宣称持久成功。这些是待移植验证的证据，尚不是新增公开能力已通过实机的声明。目录应从匹配的原生数据生成，不将游戏资源纳入 SDK 包。

## 服务契约

| 服务 | 输入和结果 | 必须验证 |
| --- | --- | --- |
| 光环 | 目录、当前五槽、指定槽装配/清空；请求绑定场景纪元 | 当前效果、HUD、换房、重复光环、检查点状态 |
| 技能 | 目录、当前四槽、受控替换；关联等级/冷却/符文明确处理 | 可施放、等级与冷却语义、关联效果、换房与保存 |
| 战斗 | 回血、补充已确认的施法资源；有限值和上限约束 | 独立原生读数与画面、死亡/过期拒绝 |
| 玩法事件 | 原生来源和顺序、事件编号、游标与溢出反馈 | 伤害/拾取/开局/结束真触发；快照差分保留原名称 |
| 插件数据 | owner + 逻辑键 + 不透明字节；读取/原子写入/删除 | 隔离、重启恢复、短缓冲、失败保留旧值、中断恢复 |
| 共享菜单 | 目录搜索、选择、执行、结果 | 键鼠操作、焦点、关闭恢复、最低尺寸、中文可读 |

当前公共 API 为 328 字节：插件数据在旧 248 字节前缀后追加，随后追加装备查询、战斗资源查询、内容目录、装备提交与结果查询，以及独立的原生玩法事件流。插件数据按 manifest id 在框架数据目录分区。逻辑键允许 1..64 位 ASCII 字母、数字、`-`、`_`；Windows 上键名不区分大小写；单值 1 MiB，每插件最多 64 个键、合计 16 MiB；不接受文件路径。插件可用 JSON 或自己的带版本二进制格式，框架不解释内容。相同 id 同时加载只能一个取得数据 owner。同步磁盘操作应在初始化或工作线程执行，卸载回调结束后撤销 owner。原生 DLL 具备进程权限，此隔离用于阻止误操作，不是恶意代码沙箱。

受控装备操作以槽位旧 ID 和场景纪元作提交条件，每次原生更新最多执行一次修改。技能替换清除该槽关联符文 ID，保留原四位原生槽位状态以及后续升级、实例身份尾部，尾部按原样保存；原生符文刷新使用 RCX 帧指针及 XMM1/XMM2 双精度玩家、槽位参数，并保留 XMM0 返回值。四槽正常轮换施法、法力消耗、跨房保留、实际存档和独立进程续局已通过实机。角色等级保持不变。技能原生升级条目和实例身份尾部按原样保留，实例关联的原生印记随之保留；不提供任意等级、印记或冷却修改。验收 75 覆盖 XV/+300%、X/+200%，替换前后签名技能 Q 冷却画面为 14，随后正常递减到 11、8。原生字段 0x1cd538 是此次观察到的时长配置，不是剩余秒数；不将它作为公共冷却字段。检查点结果 `SAVE_DISPATCHED` 只表示调用了原版保存入口，不能解释为文件落盘成功；待同步时装备发生变化，返回独立错误 `AAMOD_ERR_EQUIPMENT_CONFLICT`，不与状态编号混用。

## 菜单体验基线

目标用户为示例插件使用者；核心任务是选择光环/技能并应用，随后保存构筑。入口为插件菜单，完成证据为执行结果与当前装备一致。关闭返回游戏；失败保留草稿并显示重试条件。菜单不自行写入原游戏存档。

| 状态 | 触发与反馈 | 操作与焦点 | 保留/清理 |
| --- | --- | --- | --- |
| 初始 | 打开，展示当前装备和操作说明 | 搜索或列表，唯一可见焦点 | 清除旧按键锁存 |
| 空 | 无匹配内容，说明原因 | 修改搜索、重置、关闭 | 保留草稿 |
| 禁用 | 未进本轮/版本不匹配，展示原因 | 浏览、保存草稿、关闭 | 不提交请求 |
| 处理中 | 已提交，显示请求状态 | 阻止重复提交，允许关闭 | 保留请求编号 |
| 成功 | 显示实际装备及检查点结果 | 继续选配或保存 | 清除待执行动作 |
| 失败/过期 | 显示原因和重新采样入口 | 重试前刷新当前装备 | 保留用户选择，不重放旧请求 |
| 重启恢复 | 读取保存的带版本构筑 | 检查目录可用性再允许应用 | 保留持久数据，清除临时焦点与请求 |

验收门禁：两个公开示例完成主流程；中文长名称与空结果可读；键盘导航和真实鼠标移动切换焦点，静止指针不抢焦点；渲染/命中共享矩形；最低窗口尺寸实测；关闭后输入归还游戏；换房和重启不重放操作；保存失败可恢复。原存档/BD 文件/个人方案前后哈希不变，临时部署回滚，清理无后续价值的中间产物。
