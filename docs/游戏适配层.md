# 游戏适配层：只读身份查询

身份接口自 0.1.3-dev 建立。0.1.4-dev 增加开发中的只读场景与玩家层内坐标快照，详见《只读状态接口》；血量、程序生成房间和构筑查询尚未完成。

## 依赖方向

加载核心负责插件生命周期；独立的 game_profile 模块负责宿主文件指纹和已验证身份匹配；插件通过追加的 game_info C ABI 查询，不依赖适配实现或原始地址。渲染能力保持可选。本阶段没有 UI，因此不引入 MVC。

身份识别使用宿主可执行文件的完整 SHA-256 与文件长度，不使用文件名或环境变量推断游戏版本。映射到已加载进程的 PE 时间戳和映像大小仅作为诊断字段。文件哈希不证明运行中代码没有被其他 Mod 修改，也不提供安全认证。

## 公共契约

`AAModAPI.game_info` 追加在偏移 136，旧 128 字节前缀及 0.1.2 的 capabilities 字段均保持原位。能力位 `AAMOD_CAP_GAME_INFO` 只表示身份查询服务实现，不表示已提供玩法对象接口。

```c
if (api_size >= offsetof(AAModAPI, game_info) + sizeof(api->game_info) &&
    AAMOD_API_HAS(api, game_info) && api->game_info) {
    AAModGameInfo info = {0};
    uint32_t rc = api->game_info(&info, sizeof(info));
    if (rc == AAMOD_OK && info.identity_status == AAMOD_GAME_IDENTITY_MATCH) {
        /* 可记录已验证身份；仍须独立验证所使用的游戏对象接口。 */
    }
}
```

- 查询复制缓存到调用者的缓冲区，不产生磁盘访问、分配或游戏状态修改。初始化结束后可多线程查询；不允许与核心关闭并发使用已释放的插件 API。
- 当前 `AAModGameInfo` 为 200 字节，version=1，size 报告核心写入的结构大小。缓冲区必须至少为当前结构大小；更大的缓冲区只写入已知 200 字节，尾部保留。空指针或短缓冲区返回 AAMOD_ERR_ARGUMENT，完全不写入。
- 字符串为结构内固定数组，已终止，无借用指针。SHA-256 使用小写十六进制。
- UNKNOWN：文件哈希成功，但不在已验证表中；profile_id 和 game_version 为空、steam_app_id=0。
- IDENTITY_MATCH：文件哈希和长度精确匹配已验证身份；不表示完整玩法兼容认证。
- IDENTITY_UNAVAILABLE：文件无法读取或哈希计算失败；哈希为空。不会猜测版本。通用插件仍可加载。
- 未知宿主不会被核心整体禁止加载；游戏专用插件应显式禁用依赖特定版本的功能。当前诊断插件仅输出日志。

## 诊断插件

```powershell
./tools/build-mod.ps1 -ModDirectory ./mods/diagnostics
```

将 diagnostics.dll 和 mod.json 放到游戏 aamod/mods/diagnostics 下。启动后在 aamod/logs/aamod.log 查看 diagnostics 输出；数据目录回退时，以核心日志中的 data dir 为准。插件是可选的，安装器不会自动安装模板或诊断插件。

它是独立的 C 插件，只包含公开头，无渲染依赖、无 hook、无存档写入。旧核心缺少追加字段时输出 unavailable 提示后正常返回。

## 验证与限制

SHA-256 实现使用 Windows CNG 的增量哈希接口，依据 [BCryptHashData](https://learn.microsoft.com/en-us/windows/win32/api/bcrypt/nf-bcrypt-bcrypthashdata) 与 [BCryptFinishHash](https://learn.microsoft.com/en-us/windows/win32/api/bcrypt/nf-bcrypt-bcryptfinishhash)。测试以独立标准哈希向量及 PowerShell Get-FileHash 核对结果。

验收覆盖空文件、abc 标准向量、文件读取失败、精确匹配、摘要单字节差异、文件长度差异、未知宿主、缓冲区拒绝与尾部保留。实机验收验证诊断插件报告的身份与独立文件哈希一致；两种入口各启动 20 秒并确认 BD 模块共存，随后恢复游戏文件。该验收不包含战斗或换房。

已有引擎资料只包含部分函数锚点及历史源码布局，尚不能据此承诺当前版本的玩家/房间/构筑布局。下一阶段需建立更新线程与对象生命周期证据，按实际字段语义开放快照；Present 回调不能作为游戏状态快照的一致性保证。
