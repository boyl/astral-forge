# 更新维护工具验收

## 目标与边界

将游戏更新后的重复诊断和证据整理从私人工作区提炼到正式仓库。保持 C ABI、原生运行时和已发布 DLL 不变，不提交游戏、个人存档、BD Mod 或本机路径。工具不以游戏版本或整文件哈希作为能力白名单。

维护工具采用 CLI 与小模块：原生扫描器复用核心适配解析器；Python 负责比较、证据清单和存档校验；Windows 快照模块负责跨进程文件共享。场景输入和战斗路线仍由经过核查的隔离脚本执行，不把本轮地址与坐标包装成通用自动验收。
