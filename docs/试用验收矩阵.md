# 0.1.9-dev 试用验收矩阵

交付目标为少量开发者试用；采用可向大量开发者扩展的版本化 C ABI。双示例同进程实机回归 102 和该组合预设的独立进程恢复 106 已通过；当前完成少量开发者试用门禁，未认证大规模稳定发布。

## 验收环境

Steam Windows x64 Astral Ascent 2.6.4，单人。游戏 EXE SHA-256：`ca376d2b741f65c75c416317517d24c316dd8a32a4eae6559030797b3b9aa88b`。

本轮技能验收核心 SHA-256：`A6CC47FBC80F72C7006D1B9A16201CF5D681F0ED93952DF3C2CBE246AB486EA1`。MSVC 19.44.35228、Windows SDK 10.0.26100.0、Python 3.12.14。ABI 1，当前 API 结构 328 字节；旧前缀保持兼容。精确发行文件哈希以包内清单为准。

角色签名技能 Q 的冷却画面在替换前后保持 14，并正常递减至 11、8；内部时长配置不是剩余秒数，不公开为冷却读数。`SAVE_DISPATCHED` 仅代表调用原版保存入口；实际持久结果通过存档和下一进程验证。

源码包与运行包需要通过哈希审计、独立解压构建、十四示例编译、旧 ABI/宿主契约和安装卸载测试。具体离线门禁结果随交付报告提供。运行包不含原版游戏资源、个人存档、BD Mod 或内部验收脚本。

开发入口见[内容开发者快速开始](内容开发者快速开始.md)。Lua、任意资源注册、其他拾取类型和通用房间事件未开放。大规模稳定发布还需要扩大版本与设备覆盖、持续集成及开发者反馈周期。
