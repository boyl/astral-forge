# 原生图片替换计划的离线检查

`tools/resource-plan.py` 帮助开发者将原生图片 ID 与插件自有 PNG 绑定，生成可复核的 JSON 计划。它只读取游戏文件及 Mod 图片，不部署、不提取游戏图片、不挂钩，也不改变 SDK 能力位。0.1.7-dev 已提供独立的运行时 SDK，见 [原生图片替换接口](原生图片替换接口.md)。

输入请求如下；`imageId` 应从精确版本的原生图片索引确认，示例 ID 不代表推荐替换目标。

```json
{"schema":1,"replacements":[{"imageId":0,"png":"assets/my-image.png"}]}
```

在 PowerShell 7 中使用真实 Python 3.11+ 执行：

```powershell
& $PythonPath ./tools/resource-plan.py prepare $GameDirectory $ModDirectory ./request.json --output ./plan.json
& $PythonPath ./tools/resource-plan.py verify $GameDirectory $ModDirectory ./plan.json
```

输出文件必须不存在，不能覆盖输入、图片或游戏文件。CLI 首先验证受支持 EXE 指纹；计划绑定整个 Assets.dat 的 SHA-256 与大小、图片原生几何和 PNG SHA-256。`verify` 重新读取输入并比对完整计划；游戏库、PNG 或计划内容变化均使旧计划失效。

每个计划支持 1..16 个唯一图片 ID，同一 ID 的重复绑定明确拒绝。PNG 路径使用 `/`，必须解析为插件目录内的文件，不能含父目录跳出、绝对路径或 ADS。当前计划仅接受非交错 RGBA8，PNG 逻辑宽高必须等于原生逻辑宽高；原生缓存宽高可能含填充，不用其作为 PNG 尺寸。单张编码文件最多 32 MiB，每轴最多 8192 像素，像素最多 64 MiB。

离线检查覆盖 PNG 签名、块范围和 CRC、IHDR、连续 IDAT、结束块、受限解压长度及行过滤类型。它不实现完整颜色管理或原生纹理创建；实际像素解码继续交给核心 PNG 服务。`runtimeValidated` 与 `nativeOverrideAvailable` 固定为 false，修改标记不能通过复核。它们表示离线工具没有执行该计划的实机认证，不表示当前核心缺少 NATIVE_IMAGES 能力。

PNG 块顺序与 RGBA 可选调色板处理依据 [W3C PNG 规范](https://www.w3.org/TR/png-3/)；允许连续分块的 IDAT，不把压缩流错误当作空图片。

当前公共接口已覆盖原生上传、缓存命中更新、恢复及所有者撤销；失败路径由独立契约测试覆盖，实机确认了主菜单背景替换与恢复。离线计划通过不等同于游戏中替换成功。
