# 原生 PNG 图片替换接口

0.1.7-dev 为精确匹配的 Astral Ascent Steam Windows x64 2.6.4 提供运行时图片替换。ABI 1 保留原有 208 字节前缀，新结构为 248 字节。未知 EXE 或原生挂钩失败时不开放 `AAMOD_CAP_NATIVE_IMAGES`。该服务使用游戏自己的图形上下文，不需要开启可选 D3D 帧回调。

## 公共接口

先检查 `AAMOD_API_HAS(api,image_replacement_forget)` 与 `AAMOD_CAP_NATIVE_IMAGES`，然后使用插件自己的 `resource_owner`。接口不返回游戏指针或原生纹理句柄。

| 接口 | 行为 |
| --- | --- |
| `native_image_info(id,out,size)` | 复制逻辑/缓存尺寸、格式、是否有纹理和 `upload_visits`；尚未观察到图片时返回 `NATIVE_NOT_READY` |
| `image_replace(owner,id,png,&handle)` | 同步解码插件目录内 PNG 并复制像素，返回待执行句柄；失败不改变输出句柄 |
| `image_replacement_status(owner,handle,out,size)` | 查询状态、错误、应用与恢复次数 |
| `image_restore(owner,handle)` | 请求恢复原图；可重复调用，查询结果确认完成 |
| `image_replacement_forget(owner,handle)` | 释放已恢复的状态记录；尚未恢复返回 `NATIVE_PENDING` |

状态为 `PENDING`、`APPLIED`、`RESTORE_PENDING`、`RESTORED` 或 `FAILED`。登记成功只表示已接受；插件初始化成功后请求才会激活。失败状态应调用恢复并等待完成，再释放句柄。
原图纹理创建失败时不会报告已恢复，绑定与核心数据保留，调用者可在故障处理后显式重试恢复；核心不执行无依据的自动重试。插件已退出且原图无法重建时记录错误并保留状态到核心关闭，不能承诺设备故障中的即时恢复。

登记涉及文件读取与解码，应在初始化或工作线程调用，不能放进帧回调。图片首次到达原生上传边界后才有观察元数据。`upload_visits` 不是可见次数：多数缓存精灵会跳过该函数，不能用它判定屏幕内容。

核心在正常原生图形边界处理待执行请求，完成原生分配、预乘 alpha、后端方向处理和纹理创建；已缓存图片也可替换。缓存被游戏释放并重建后，激活的替换再次应用。恢复会释放替换纹理，从原生资源重建原图并还原裁剪、填充与格式。源 PNG 后续改变不会影响已登记的核心像素副本。

## 几何、冲突与生命周期

PNG 必须等于原图逻辑宽高，包含所需透明边距；不能按经过裁剪或对齐的原缓存尺寸制作。替换使用完整逻辑尺寸 RGBA8，恢复使用原生几何。图片 ID 为 0..71869，只属于该精确版本。

路径、中文文件名、目录越界链接、格式及单图限额沿用 [PNG 资源接口](PNG资源接口.md)。每插件最多保留 16 个请求与 64 MiB 像素，全局最多 128 个请求与 256 MiB 像素。同一 ID 同时只能有一个请求，包含尚未恢复的请求；重复登记返回 `NATIVE_CONFLICT`，不会按加载顺序静默覆盖。已恢复记录仍占数量，使用 `image_replacement_forget` 后可再次登记。

不能用本插件的 owner 操作他人句柄。初始化失败取消待执行请求；退出时拒绝新请求，并安排已应用图片恢复。恢复前核心保留自己的像素副本，不引用已退出的插件代码或内存。旧请求的清理不能删除另一个插件后来创建的绑定。

这不代表 DLL 热重载已开放。核心显式关闭仍要求先停止游戏/渲染循环；进程退出后游戏销毁其缓存纹理。详见 [开发者起步](开发者起步.md)。原生插件是可信进程内代码，owner 不是安全沙箱。

## 独立示例

`mods/native_image_sample` 只使用公共 SDK，默认禁用。在 `aamod/config.ini` 配置：

```ini
[native_image_sample]
image_id=33917
restore_seconds=120
repeat_count=1
```

ID 33917 已由主菜单对象引用及实机画面确认是 1600×900 背景，是版本限定的演示目标。`image_id=-1` 为只读观察模式；重复次数为 1..16，恢复时间为 1..3600 秒，从应用成功开始计时。

PowerShell 7 中生成自有测试图并编译：

```powershell
& $PythonPath ./tools/create-image-fixture.py 1600 900 ./mods/native_image_sample/assets/replacement.png
./tools/build-mod.ps1 -ModDirectory ./mods/native_image_sample
```

生成器拒绝覆盖已有文件。预览包已含该自制图片，可直接编译或部署。将示例复制到游戏 `aamod/mods`，在该副本 `mod.json` 中启用后启动；它替换背景、定时恢复、查询完成并释放句柄。包中不含原生素材、存档或私有探针。

离线契约覆盖初始化提交/回滚、所有者与冲突、裁剪/填充、缓存复用/重建、颜色/方向、取消/恢复、错误、限额和状态释放；PNG 副本也覆盖与所有者撤销并发。实机确认背景可见、四象限方向与半透明正确、恢复原图，以及重复替换/恢复/释放和正常转场。尚未认证所有图片、地图、图形设备重建或热重载。
