# 小范围开发者试用版交付流程

目标：包内文件足以让熟悉 C/C++ 的开发者独立安装、编译插件、离线加载和定位错误。长期按多人使用维护，本阶段不是稳定版认证。

## 开发者最短路径

运行预览解压到可写目录。需要 Windows x64、PowerShell 7 与 Visual Studio C++ Build Tools；只编译和离线加载插件不需要 Python 或游戏。构建整个源码和运行资源计划工具需要 Python 3.11+，现有 Python 工具只使用标准库。

```powershell
Copy-Item ./mods/template ./mods/my_mod -Recurse
# 修改 my_mod/mod.json 的 id、entry 与源码；entry 对应生成的 DLL 文件名。
./tools/build-mod.ps1 -ModDirectory ./mods/my_mod
./tools/test-mod.ps1 -ModDirectory ./mods/my_mod -ReportPath ./my_mod-test.json
```

test-mod 在独立临时目录启动不依赖 GPU 的 SDK 宿主，验证初始化、重复关闭及核心归属资源归零；临时目录自动清理。这个宿主的 EXE 不受游戏适配支持，不能用于验证真正游戏行为。原生图片或回血插件声明必需能力后会被正确拒绝；先用 template/image_sample 验证工具链，再在隔离游戏中测试实验服务。禁用插件须在测试副本中显式启用，工具不会修改原清单。

关闭游戏，用 install.ps1 -WhatIf 预览安装，再执行安装。安装器不自动部署包中的示例，将自己的 DLL、mod.json 及自有 assets 放入游戏 aamod/mods/<id>。使用 launch-game.ps1 启动；命令需要 -Commands，渲染回调需要 -Render。原生图片替换无需渲染开关。先用测试存档，保留自己能恢复的备份；公共启动器不会自动建立存档隔离。

编译采用 /MD，运行机器需要对应 x64 Visual C++ 运行库。具有构建工具的开发机器可先以独立 SDK 宿主确认运行依赖；预览包不捆绑微软运行库或系统 DLL，不下载或自动安装依赖。

## 维护者门禁

1. 完整 build.ps1 -Test、run-contracts.ps1、run-installer.ps1 通过，记录工具链和结果。
2. 编译十四个公开示例，以 package-preview.ps1 生成新的本地预览，不覆盖历史包。
3. audit-preview.py 核对归档、逐文件哈希、源码快照、默认开关及禁止负载。
4. run-package.ps1 从归档解压至独立路径，在新的 pwsh 进程中清除 AAMOD 与编译环境覆盖，从源码重建、编译公开示例、验证加载、安装和卸载。不把同一主机的独立目录称为另一台机器验收。
5. 最终候选运行游戏增量验证，复核实际加载 SHA、功能效果、回滚和原存档。以前版本的结果不自动转移给新候选。
6. 交付源码/运行包、SHA 清单、已验证矩阵、未覆盖范围及问题反馈入口。清理完成测试的临时目录与编译中间产物，保留可复用脚本、候选和证据。

```powershell
./tools/package-preview.ps1 -OutputDirectory '<新的交付目录>'
& '<Python路径>' ./tools/audit-preview.py '<交付SHA清单>'
./tests/run-package.ps1 -ManifestPath '<交付SHA清单>' -PythonPath '<Python路径>' -ReportDirectory '<新的报告目录>'
```

源码快照和工具链使构建流程可重做；当前不承诺不同路径、工具链或系统产生字节完全相同的 DLL。归档按最终候选哈希核对，不能用重新编译但哈希不同的 DLL 替换实机候选。

## 正式对外发布

本地开发者预览可以先审阅和试用。正式公开发布须绑定已审计的 Git 提交，配置真实项目远端、验证提交与远端 SHA，从该提交重建并重新验收最终候选；发布说明必须给出范围和实验标记。未配置远端、未提交、未通过实机或外部机器验收时，不能声称已公开发布或普遍兼容。

GitHub Actions 工作流仅执行离线构建与验证，不启动游戏、不发布 Release，也不上传游戏或存档。流程参考 [GitHub 官方 PowerShell 构建说明](https://docs.github.com/en/actions/tutorials/build-and-test-code/powershell)；只有实际远端运行成功才能报告 CI 通过。
